**Исходный файл:** `Аргумент - главная (v2).dc.html` (501 строка, инлайн-стили, формат Claude Design `x-dc`)
**Основание:** прямой разбор кода, не скриншот. Все контрастные отношения посчитаны по WCAG 2.x (sRGB, относительная яркость).
**Дата:** 07.09.2026

## 0. Как это использовать

Проходы **П0 → П5** выполняются **строго по одному**. Каждый следующий опирается на токены и решения предыдущего. Не передавайте документ целиком в генератор кода одним запросом — П2 без П1 сломает сетку, П4 без П0 не найдёт токенов.

После каждого прохода — прогнать чек-лист приёмки этого прохода, только затем переходить дальше.

**П5 требует отдельного подтверждения заказчика** (меняет визуальный характер секции). П0–П4 — техническая правка, характер макета не меняют.

## 3. Общее правило для всех замен

Инлайн-стили содержат значения-префиксы (`1.3` — префикс `1.35`, `1.6` — префикс `1.65`, `1` — префикс всего). **Наивный `find & replace` по подстроке испортит файл.**

Все замены выполнять с якорем конца значения:

```
line-height:1\.3(?=[;"'])     →  line-height:1.35
font-size:14\.5px(?=[;"'])    →  font-size:16px
```

Порядок внутри прохода: сначала самые длинные значения, потом короткие.
