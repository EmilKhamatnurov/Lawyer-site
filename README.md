# АРГУМЕНТ — статический сайт

Сайт состоит из главной страницы и шести страниц услуг. Для просмотра откройте `index.html` в браузере; сборка и установка пакетов не требуются.

## Структура

- `index.html` — главная страница. Разметка, стили и логика находятся в этом файле; она использует сгенерированный `support.js`.
- `*.html` с названиями услуг — самостоятельные страницы услуг.
- `assets/service.css` и `assets/service.js` — общие стили и поведение всех страниц услуг (меню и форма письма).
- `assets/vendor/` — локальные копии React и ReactDOM, необходимые главной странице.
- `img/` — изображения сайта.
- `uploads/` и ZIP-архив — исходные материалы, не используемые страницами сайта.

## Как вносить изменения

Текст и разметку услуги редактируйте в соответствующем HTML-файле. Общий вид и поведение страниц услуг меняйте в `assets/service.css` и `assets/service.js`. Главную страницу редактируйте в `index.html`.

`support.js` — сгенерированный runtime без исходников в этом репозитории. Его не следует править вручную. Действующие ссылки между страницами используют относительные пути, поэтому сайт можно перенести на другой домен или открыть локально.

Форма на главной показывает подтверждение в интерфейсе, но не отправляет данные на сервер. Формы на страницах услуг создают письмо через почтовую программу посетителя (`mailto:`). Для реальной отправки заявок потребуется отдельный обработчик.
