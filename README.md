# АРГУМЕНТ — статический сайт

Сайт состоит из главной страницы, шести страниц услуг и базового раздела новостей. Для просмотра откройте `index.html` в браузере; сборка и установка пакетов не требуются.

## Структура

- `index.html` — главная страница. Разметка и логика находятся в этом файле; она использует сгенерированный `support.js` и стили `assets/home.css`.
- `*.html` с названиями услуг — самостоятельные страницы услуг.
- `assets/service.css` и `assets/service.js` — общие стили и поведение всех страниц услуг (меню и форма письма).
- `news.html` — список материалов; `news-*.html` — черновые страницы отдельных материалов. Их стили и фильтр находятся в `assets/news.css` и `assets/news.js`.
- `assets/vendor/` — локальные копии React и ReactDOM, необходимые главной странице.
- `img/` — изображения сайта.
- `uploads/` и ZIP-архив — исходные материалы, не используемые страницами сайта.

## Как вносить изменения

Текст и разметку услуги редактируйте в соответствующем HTML-файле. Общий вид и поведение страниц услуг меняйте в `assets/service.css` и `assets/service.js`. Главную страницу редактируйте в `index.html` и `assets/home.css`. Новые материалы добавляйте отдельными HTML-файлами и ссылками в `news.html` и `index.html`.

`support.js` — сгенерированный runtime без исходников в этом репозитории. Его не следует править вручную. Действующие ссылки между страницами используют относительные пути, поэтому сайт можно перенести на другой домен или открыть локально.

Все формы создают письмо через почтовую программу посетителя (`mailto:`). Для отправки заявок через сайт потребуется отдельный обработчик. Три страницы материалов пока обозначены как черновики; перед публикацией необходимо заменить краткие описания проверенными текстами.
